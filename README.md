## 📌 نحوه کارکرد

REN Gateway یک تونل VLESS روی WebSocket است که روی Render یا Railway (هاست رایگان) اجرا می‌شود.

نیازی به سرور VPS ندارید. فقط کافیه پروژه را فورک کنید و روی Render یا Railway دیپلوی کنید.

بعد از دیپلوی، یک آدرس بهتون داده می‌شود که پنل مدیریت شماست.

### خلاصه نحوه استفاده:

- 📱 اپلیکیشن v2rayNG یا NekoBox را نصب کنید
- 🔗 لینک VLESS را از پنل کپی کنید
- 📲 لینک را در اپلیکیشن وارد کنید
- ✅ اتصال برقرار شد!

## ⚡ شروع سریع (Render)

> ## 🚨 هشدار مهم — ساسپند شدن در Render
>
> **در حال حاضر Render سرویس‌هایی که به صورت دستی (فورک و دیپلوی مستقیم) راه‌اندازی می‌شوند را ساسپند می‌کند.**
>
> ### ✅ راه‌حل: دیپلوی از طریق بات [@REN_WZA_BOT](https://t.me/REN_WZA_BOT)
>
> برای جلوگیری از ساسپند شدن سرویس، دیپلوی را **فقط از طریق بات تلگرام** انجام دهید. بات به صورت خودکار سرویس را به روشی امن دیپلوی و مدیریت می‌کند. مراحل دستی زیر صرفاً جهت اطلاع و مستندسازی باقی مانده‌اند.

### ۱. فورک کنید
- روی دکمه **Fork** بالای این صفحه کلیک کنید

### ۲. به Render بروید
- به [render.com](https://render.com) بروید
- با اکانت GitHub وارد شوید
- روی **New** → **Web Service** کلیک کنید
- مخزن فورک شده خود را انتخاب کنید

### ۳. تنظیمات دیپلوی
- **Build Command:** `pip install -r requirements.txt`
- **Start Command:** `python main.py`
- **Name:** هر اسمی که دوست دارید
- **Region:** Frankfurt (Germany) برای پینگ بهتر
- ⚠️ **Plan:** حتماً **Free** را انتخاب کنید

### ۴. دیپلوی کنید
- روی **Deploy** کلیک کنید
- ⏳ حدود ۲-۳ دقیقه صبر کنید

### ۵. وارد پنل شوید
- بعد از دیپلوی، Render یک آدرس مثل این بهتون می‌ده:
  ```
  https://your-app-name.onrender.com
  ```
- آدرس پنل شما:
  ```
  https://your-app-name.onrender.com/login
  ```
- رمز عبور پیش‌فرض: `admin`
- ⚠️ بعد از ورود حتماً رمز عبور را از بخش Security تغییر دهید

⚠️ **نکته مهم:** فقط Render از آی‌پی‌های Cloudflare پشتیبانی می‌کند. اگر می‌خواهید از آی‌پی تمیز Cloudflare استفاده کنید، حتماً Render را انتخاب کنید.

## ⚡ شروع سریع (Railway)

### ۱. فورک کنید
- روی دکمه **Fork** بالای این صفحه کلیک کنید

### ۲. به Railway بروید
- به [railway.com](https://railway.com) بروید
- با اکانت GitHub وارد شوید (دقیقاً مثل Render)
- روی **New Project** → **Deploy from GitHub Repo** کلیک کنید
- مخزن فورک شده خود را انتخاب کنید
- روی **Deploy** بزنید و منتظر بمانید تا تمام شود

### ۳. تنظیمات ریجن
- بعد از دیپلوی، روی پروژه کلیک کنید
- به بخش **Settings** بروید
- قسمت **Scale** را پیدا کنید
- ریجن را روی **Amsterdam** تنظیم کنید تا پینگ بهتری داشته باشید

### ۴. وارد پنل شوید
- بعد از دیپلوی، Railway یک آدرس مثل این بهتون می‌ده:
  ```
  https://your-app-name.up.railway.app
  ```
- آدرس پنل شما:
  ```
  https://your-app-name.up.railway.app/login
  ```
- رمز عبور پیش‌فرض: `admin`

## 🎯 آی‌پی تمیز (Clean IP)

### آی‌پی تمیز چیست؟
آی‌پی تمیز یک IP یا دامنه است که می‌تواند پینگ بهتری برای شما فراهم کند. استفاده از آی‌پی تمیز اختیاری است ولی توصیه می‌شود.

### چطور استفاده کنیم؟
1. وارد پنل شوید
2. بخش **Clean IP** را باز کنید
3. آدرس‌های دلخواه خود را اضافه کنید (هر تعداد که بخواهید)
4. کانفیگ‌ها خودکار با آی‌پی‌های تمیز ساخته می‌شوند

⚠️ **نکته مهم:** فقط Render از آی‌پی‌های Cloudflare پشتیبانی می‌کند. Railway از Cloudflare IPs پشتیبانی نمی‌کند.

## 🎯 استفاده از پنل

### ساخت لینک VLESS
1. وارد پنل شوید
2. روی **+ Add** کلیک کنید
3. یک نام انگلیسی وارد کنید (مثلاً: `Ali`)
4. حجم مصرفی را مشخص کنید (مثلاً: `1` GB)
5. روی **Create** کلیک کنید
6. لینک VLESS را کپی کنید یا QR Code را اسکن کنید

### اتصال با اپلیکیشن
1. اپلیکیشن **v2rayNG** یا **NekoBox** را نصب کنید
2. لینک VLESS را وارد کنید
3. اتصال را فعال کنید
4. 🎉 تمام! حالا می‌توانید از اینترنت آزاد استفاده کنید

### مدیریت لینک‌ها
- 🔍 **جستجو:** در بخش Inbounds می‌توانید لینک‌ها را جستجو کنید
- 🏷️ **فیلتر:** لینک‌ها را بر اساس وضعیت (فعال/غیرفعال) فیلتر کنید
- ⚡ **فعال/غیرفعال:** با کلیک روی دکمه Toggle لینک را فعال یا غیرفعال کنید
- 📊 **مصرف:** مصرف حجم هر لینک را ببینید
- ✏️ **ویرایش:** با کلیک روی دکمه Edit حجم و IP لیمیت را تغییر دهید
- 🗑️ **حذف:** لینک‌های بدون استفاده را حذف کنید

🔍 ریشه مشکل در تصویر

در بخش START COMMAND، هنوز یک متن پیش‌فرض و ناقص وجود دارد:
npm start · uvicorn app.main:app --host 0.0.0.0 --po

این خط دو مشکل دارد:

1. عبارت npm start · اضافی است.
2. دستور پایتون ناقص است و به جای --port $PORT نوشته شده --po.
3. مسیر ماژول (app.main:app) اشتباه است، فایل شما main.py است و باید main:app باشد.

🛠️ راه‌حل قطعی (گام‌به‌گام در پنل PandaStack)

قدم اول: اصلاح دستورات در پنل
۱. در همان صفحه‌ای که تصویر فرستادید (بخش Build & runtime):
۲. کادر INSTALL COMMAND را کاملاً پاک کنید و فقط این را بنویسید:
pip install -r requirements.txt
۳. کادر START COMMAND را کاملاً پاک کنید (کل متن npm start · uvicorn... را حذف کنید) و دقیقاً این را بنویسید:
uvicorn main:app --host 0.0.0.0 --port $PORT
۴. کادر BUILD COMMAND را خالی بگذارید.
۵. مطمئن شوید PORT روی 3000 است.

قدم دوم: ذخیره و اجرا
۶. روی دکمه Save & redeploy (ذخیره و اجرای مجدد) در پایین صفحه کلیک کنید.
۷. این بار پروژه بدون خطا اجرا می‌شود.

قدم سوم: غیرفعال کردن خواب سرور (Auto Hibernate)
در همان صفحه تنظیمات، کمی به پایین اسکرول کنید تا به بخش Advanced یا Resources برسید (یا در برخی پلن‌ها، گزینه‌ای در همان صفحه اول وجود دارد).

· گزینه‌ای با عنوان Auto Hibernate یا Sleep on Idle را پیدا کنید.
· آن را روی غیرفعال (Off) قرار دهید.
· دوباره Save کنید.

💡 چرا فایل pandastack.json کار نکرد؟

PandaStack همیشه اولویت را به تنظیمات وارد شده در پنل (UI) می‌دهد تا فایل JSON. چون در پنل شما دستور اشتباه وارد شده بود، فایل JSON نادیده گرفته شده بود. اکنون که دستور را در پنل اصلاح می‌کنید، فایل JSON هم می‌تواند به عنوان پشتیبان عمل کند.
